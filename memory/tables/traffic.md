# traffic 流量表

- 用途：各二级品类每日流量（访客/浏览/加购）；回答「转化率、流量趋势、品类热度」类问题
- 粒度：一行 = 一天一二级品类；唯一键 (dt, category_id)；与 categories 是 N:1
- 时间字段：dt（DATE，分区字段）——**所有查询必须带 dt 过滤**（左闭右开区间）
- 字段表：

| 字段 | 类型 | 含义 | 口径/取值 | 备注 |
|---|---|---|---|---|
| dt | DATE | 日期（分区字段） | — | 复合主键之一，所有查询必须过滤 |
| category_id | INT | 二级品类ID | — | 复合主键之一；一级口径需上卷 |
| uv | BIGINT | 独立访客数 | 当日去重访客 | 转化率分母 |
| pv | BIGINT | 页面浏览量 | — | 浏览漏斗指标 |
| cart_cnt | INT | 加购数 | — | 加购漏斗指标（注意：不是 visit_amt，真实 schema 以此为准） |

- 指标口径：
  - 访客数（月度）：SUM(uv)（**人次口径**——跨天访客重复计入，本表粒度无法跨天去重，解读时注明）
  - 下单转化率：支付订单数（orders：pay_dt IS NOT NULL，按下单日 order_dt） / SUM(uv)
  - 加购率：SUM(cart_cnt) / SUM(uv)
- 注意事项/坑：
  - uv 跨天求和会重复计访客 → 月度「访客数」是人次口径不是去重人数；
    做周期对比时口径一致即可，不要对外宣称「独立访客数」
  - 转化率的分子（支付订单）需经 order_items 按品类归属，跨品类订单在品类间重复计分子
    → 品类转化率是「品类视角」指标，与整体转化率的分母口径一致但分子归属不同
  - category_id 是二级品类 → 一级品类口径用 COALESCE(parent_id, category_id) 上卷
  - cart_cnt 是加购数，与下单转化率是**不同漏斗环节**（加购率 ≠ 下单率），不要混用
- 常用过滤：
  - `dt >= '2026-07-01' AND dt < '2026-08-01'`（单月流量）
  - `category_id = 101`（单品类）
- 关联键：
  - category_id → categories.category_id（N:1，取品类名/上卷一级）
